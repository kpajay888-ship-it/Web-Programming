TEXT STYLES

HTML(Hyper text markup language) is the most basic building block of the web.
it defines the meaning and structure of web content. other technologies besides HTML are generally used to describe a web pages's appearence/presentation(CSS) functionality/behaviour(Javascript)


The HTML styles attribute is used to add styles to an element, such as color ,font,size and more.


BOLD-the"b" tag in HTML is used to specify the bold text without any extra importance the text is written with "b" tag display in bold size you can do that by using font-weight:bold; properly in css. it is a container tag that contains an opening tag, content and closing tag.


italics - the "i" tag defines a part of text in an alternative voice or mood. the contentinside is typically displayed in italic.the "i"tag is often used to indicate a technical term,a phrase from another language ,a thought,a ship name,etc.


underline-The "u"tag in html stands for underline ,and its used to underlinethe text enclosed within this"u"tag this tag is generally used to underline misspelled words.this tag requires a starting as well asending tag.
